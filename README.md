# FlowForm

FlowForm 소스는 [GPL-3.0-or-later](LICENSE)로 공개합니다. 함께 배포되는 구성 요소의 라이선스와 소스는 [제3자 구성 요소 안내](installer/third-party/README.md)에서 확인할 수 있습니다.

FlowForm은 Windows용 로컬 CAD와 OpenFOAM 유동해석 앱입니다. [Windows 설치 파일](https://github.com/teho00/flowform-releases/releases/latest)은 GitHub Releases에서 받을 수 있습니다. 3D CAD는 Open CASCADE로 솔리드를 만들고 STEP을 입출력합니다. 유로 유동해석은 CAD에서 지정한 유체 체적을 받아 격자와 해석 케이스를 만듭니다. CFD 벤치마크는 동봉된 평행 평판 유로의 압력강하와 중앙 단면 속도를 이론해와 비교합니다.

## 3D CAD 실행

Windows PowerShell에서 프로젝트 폴더로 이동해 Python 3.12 가상환경에 CAD 커널을 설치합니다. 3D 보기에는 WebGL을 지원하는 브라우저를 사용합니다.

```powershell
git clone https://github.com/teho00/flowform-releases.git
Set-Location -LiteralPath '.\flowform-releases'
python -m venv .cad-venv
.\.cad-venv\Scripts\python.exe -m pip install -r requirements-cfd.txt
.\.cad-venv\Scripts\python.exe app.py --demo --runs-dir demo-runs
```

[3D CAD](http://127.0.0.1:8000/cad)를 엽니다. `--demo`는 CFD 벤치마크의 합성 데이터 모드이며 CAD 연산은 해당 옵션과 관계없이 실제 솔리드에 적용됩니다.

1. 뷰포트 왼쪽 아래 삼축에서 **XY**, **YZ**, **XZ** 중 하나를 선택해 2D 스케치를 엽니다. 솔리드에서는 평평한 면을 클릭하고 **선택면 스케치**를 누릅니다. 같은 면을 다시 선택하면 기존 스케치를 이어서 편집합니다. 점은 클릭하고, 선·사각형·원·타원은 드래그합니다. 작업 단위는 mm입니다.
2. **2D 스케치 편집**에서 **선택** 도구로 닫힌 윤곽 안쪽을 끌면 그 윤곽만 스케치 평면 위에서 이동합니다. 윤곽이 겹칠 때는 편집 패널의 **스케치 1**, **스케치 2** 목록에서 원하는 윤곽을 먼저 선택합니다. 윤곽선이나 끝점을 끌면 치수가 바뀝니다.
3. **3D 모델링으로 돌아가기**를 누르면 스케치 편집이 끝납니다. **상면**은 3D 모델링에서 볼 방향을 바꾸는 버튼입니다. 3D 모델링에서 윤곽 안을 끌면 **영역 끌기 작업**의 **자동**, **돌출·결합**, **절삭** 설정이 적용됩니다. **자동**은 기존 면 바깥 방향으로 돌출하고 안쪽 방향으로 절삭합니다. 스냅이 켜져 있으면 결합할 끝면이 가까운 평행 면과 겹칠 때 거리가 맞춰집니다. 솔리드의 평면은 법선 방향으로, 원통 옆면은 반지름 방향으로 끌어 크기를 바꿉니다. 솔리드 모서리를 부품 안쪽으로 끌면 필렛 반지름이 커집니다.
4. 드래그 중에는 커서 옆에 치수가 표시되며, 면 편집과 필렛은 적용 후 형상의 와이어프레임을 함께 보여줍니다. 놓으면 적용되고 `Esc`로 취소할 수 있습니다. 뷰포트에서 요소를 더블클릭하면 치수를 입력할 수 있습니다. 필렛 반지름에 `0`을 입력하면 각진 모서리가 복원됩니다.
5. 왼쪽 **파트 및 피처** 트리에서 파트와 스케치를 펼쳐 관련 작업을 볼 수 있습니다. 파트나 스케치를 선택하고 `F2` 또는 행의 연필 버튼을 눌러 이름을 바꿉니다. 피처는 트리에서 더블클릭하거나 행의 편집 버튼으로 엽니다. 뷰포트 오른쪽 아래의 **원점** 버튼은 `(0, 0, 0)`을 화면 중앙에 가져옵니다.
6. **STEP 가져오기**로 불러온 닫힌 솔리드에도 면 스케치와 형상 편집을 사용할 수 있습니다. 프로젝트 파일에는 스케치와 파트별 작업 이력이 저장됩니다. 부품 형상과 이력에서 선택한 절삭으로 만든 유체 체적은 각각 STEP으로 다운로드합니다.

`Del` 또는 **선택 삭제**로 2D에서 선택한 요소나 닫힌 윤곽, 트리에서 선택한 스케치나 파트를 지웁니다. 마지막 요소를 지우면 스케치도 트리에서 사라집니다. 스케치를 지우면 그 스케치를 참조하는 돌출·절삭도 함께 삭제되며 `Ctrl+Z`로 복원할 수 있습니다. 겹친 닫힌 윤곽의 내부선을 선택해 `Del`을 누르거나 **겹친 윤곽 합치기**를 누르면 3D에서 사용할 바깥 경계가 하나로 정리됩니다. 단순한 직선형 원통의 위·아래 원형 면을 더블클릭하면 높이와 반지름을 함께 입력할 수 있으며, 반대쪽 끝의 위치를 기준으로 편집합니다.

### 정밀 스케치와 유로 윤곽

- 선·사각형·원·타원의 첫 기준점을 놓고, 다음 점을 정하는 동안 숫자나 `Space`를 누르면 치수를 입력할 수 있습니다. `Tab`으로 치수 항목을 이동하고 `Enter`로 확정합니다. 스냅을 잠시 해제하려면 `Shift`를 누른 채 움직입니다.
- 교차점으로 둘러싸인 영역은 3D에서 각각 끌 수 있습니다. 2D의 **트림**은 강조된 구간을 지우며 **분할**은 클릭 위치에서 곡선을 나눕니다. 열린 윤곽의 끝점은 빨간색으로 표시됩니다. **보조선 전환**으로 기준이 되는 선이나 도형을 영역 판정에서 제외할 수 있습니다.
- **3점 호**는 시작점·통과점·끝점 순으로 찍습니다. **접선 호**는 선 또는 원호의 끝점에서 시작합니다. **코너 라운드**에서 이어질 두 직선을 선택하고 반지름을 입력합니다.
- 유로는 직선과 원호로 이은 열린 중심선을 그린 후 **유로 오프셋**에서 그중 한 곡선을 클릭하고 전체 폭을 입력합니다. 중심선은 보조선으로 바뀌고, 양쪽 벽과 양 끝을 닫는 선이 생깁니다. 교차나 분기가 없고 곡선 연결부가 접하는 중심선을 사용합니다. 직선끼리 만나는 코너도 사용할 수 있습니다.
- 기존 유로의 스케치를 다시 열고 오른쪽 **유로 치수**에서 **폭 편집** 또는 각 **턴 반지름**을 선택합니다. 뷰포트에서 벽을 더블클릭해도 치수를 열 수 있습니다. 폭이나 반지름을 바꾸면 벽과 끝단을 다시 계산하고, 같은 윤곽을 참조한 돌출·절삭을 갱신합니다. 수치 변경으로 벽이 서로 교차하거나 안쪽 반지름이 사라지면 이전 형상이 유지됩니다.
- 이미 접선으로 이어진 직선과 원호는 반지름을 수정할 때 끝점과 접선을 함께 유지합니다. 유로를 개별 선·호로 직접 편집하려면 **유로 치수 → 연결 해제**를 누릅니다.
- 이전 버전의 유로도 중심선과 벽·끝단이 당시 오프셋 결과와 정확히 일치하면 열 때 **유로 치수**에 연결합니다. 개별 편집된 이전 윤곽은 기존 스케치로 엽니다.
- **모서리 투영**에서 솔리드의 직선 또는 평행한 원형 모서리를 선택해 스케치 위의 보조선을 만듭니다. 투영한 보조선은 당시 모서리 위치를 저장합니다. 스케치 치수가 바뀌면 축에 평행한 외곽 전체 모서리의 필렛은 위치를 다시 맞춥니다. 유일한 모서리를 찾지 못하면 관련 피처가 트리에 표시됩니다.

### 스케치 단축키

| 키 | 동작 |
|---|---|
| `L`, `R`, `C`, `T`, `S` | 선, 사각형, 원, 트림, 선택 |
| `K`, `D` | 선택한 면 또는 마지막 스케치 편집, 3D 모델링 복귀 |
| `V` | 현재 스케치 평면을 정면으로 보기. 편집 모드는 그대로 유지 |
| `P` | 3D 당기기. 윤곽을 끌어 돌출하거나 절삭 |
| `M` | 2D에서는 스케치 이동. 3D에서는 부품의 X·Y·Z 이동값 입력 |
| `Ctrl+←`, `Ctrl+→` | 작업 평면을 법선 방향으로 각각 −1 mm, +1 mm 옮김. 기존 스케치가 있는 경우 평행한 작업 평면에서 이어서 그림 |
| `Shift+↑/↓`, `Shift+←/→` | 그리는 중 첫 번째·두 번째 치수를 각각 조절. 기본 간격은 0.1 mm 또는 1°. `Alt`를 더하면 10분의 1, `Ctrl`을 더하면 10배 |
| `Ctrl+Z`, `Ctrl+Y` 또는 `Ctrl+Shift+Z` | 실행 취소, 다시 실행 |

STEP 입력은 최대 4 MiB의 솔리드입니다. 유체 체적 생성은 개별 절삭 형상을 대상으로 합니다. **치수 피처와 부품 이동**에서 숫자 입력과 솔리드 이동을 사용할 수 있습니다. 아래 CFD 벤치마크는 동봉된 직선 유로를 사용합니다.

```powershell
.\.cad-venv\Scripts\python.exe -B -m unittest -v test_app test_cad
```

## OpenFOAM으로 실행

### CAD 유로 격자 생성과 해석

1. CAD의 트리에서 절삭 피처를 열고 **이 절삭으로 유체 체적 만들기**를 누릅니다. 하나의 연결된 유체 체적을 만든 뒤 상단 **유동해석 설정**을 누릅니다. 이 시점의 CAD 프로젝트가 해석 화면으로 전달됩니다. 해석 화면에서 같은 CAD 프로젝트 JSON을 직접 열 수도 있습니다.
2. 유체 체적의 평면 중 입구와 출구를 각각 지정합니다. 3D 뷰 또는 면 목록에서 선택합니다. U턴처럼 두 끝이 같은 평면에 있으면 면 중심 좌표로 구분합니다. 나머지 면은 무미끄럼 고정 벽입니다.
3. 입구 속도 또는 체적 유량, 출구 게이지 압력, 유체 밀도와 동적 점도, 목표 격자 길이를 지정합니다. 공기·물·수소 기본값과 직접 입력을 지원합니다. 정상과 비정상 모두 등온 비압축 단상 층류를 계산합니다. 비정상에서는 종료 시간과 최대 시간 간격을 지정합니다.
4. **격자 생성**의 기본은 **Hex Dominant (헥스 도미넌트)**입니다. 일정한 직사각 단면에는 이 방식과 **Hex Sweep (육면체 스윕)**을 사용할 수 있습니다. 원형 단면 등에는 **Tetrahedral HXT (사면체)**를 직접 선택할 수 있습니다. CAD 좌표는 mm이며, OpenFOAM용 좌표는 m로 저장합니다.
5. **생성된 격자**에서 색으로 구분된 입구·출구·벽의 실제 격자면을 돌려 보세요. X, Y, Z 단면을 선택하고 슬라이더를 움직이면 저장된 셀이 해당 평면과 만나는 모양이 표시됩니다. 좌표 단위는 mm입니다. 화면에 일부 요소만 표시되는 큰 격자도 해석과 다운로드에는 전체 셀을 사용합니다.
6. **이 격자로 해석 실행**을 눌러 원본 입구·출구와 셀을 그대로 사용하는 새 계산을 만듭니다. 저장된 해석 조건이 채워지며 모드, 유체 물성, 입구 조건, 출구 압력을 고칠 수 있습니다. CAD 형상이나 입구·출구 면을 변경한 경우 새 격자를 생성합니다. 처음부터 격자를 만들어 해석하려면 설정의 **유동해석 실행**을 사용합니다.
7. 앱은 격자 변환·검사, 솔버 실행, 후처리의 상태와 로그를 표시합니다. 계산이 끝나면 입구·출구 면적 가중 평균 압력, 압력차와 최종 시점의 **유동 컨투어**를 표시합니다. 게이지 압력(Pa)과 속력(m/s)을 바꾸고, 전체 표면과 X·Y·Z 단면을 선택할 수 있습니다. 단면에는 셀 중심값을, 전체 표면에는 경계면 값을 표시합니다. 색상 범위는 해당 물리량의 전체 격자에서 계산하므로 단면을 옮겨도 유지됩니다. CSV에는 전체 셀의 중심 좌표, 속도 성분, 속력과 압력이 들어 있습니다. 결과와 이력은 `<runs-dir>/flow/<실행 ID>/`에 저장됩니다.

Windows에서 CAD 서버를 실행하는 경우, 기본 WSL2 Ubuntu 배포판에 OpenFOAM Foundation v14가 `/opt/openfoam14`에 설치되어 있으면 유로 해석 화면이 이를 감지합니다. Windows PowerShell에서 `--demo` 없이 시작하면 기존 브라우저에서 해석을 요청할 수 있습니다. 기존 격자 이력을 쓰려면 이전과 같은 `--runs-dir` 경로를 지정하세요. 경로는 `flow`의 상위 폴더입니다. [OpenFOAM Windows 설치 안내](https://openfoam.org/download/windows/) · [Foundation v14 Ubuntu 패키지](https://openfoam.org/download/14-ubuntu/)

```powershell
.\.cad-venv\Scripts\python.exe app.py --runs-dir runs
```

WSL Ubuntu에서 CAD 서버를 직접 실행할 수도 있습니다. 케이스 ZIP을 받은 경우에는 OpenFOAM 환경에 압축을 풀고 안의 `README.txt` 명령으로 실행할 수 있습니다.

```bash
cd ~/flowform-releases
source /opt/openfoam14/etc/bashrc
sudo apt install python3-venv libglu1-mesa
python3 -m venv ~/.venvs/openfoam-cfd
~/.venvs/openfoam-cfd/bin/python -m pip install -r requirements-cfd.txt
~/.venvs/openfoam-cfd/bin/python app.py
```

[유로 유동해석](http://127.0.0.1:8000/flow)을 엽니다. 포트를 변경하면 CAD와 유동해석 화면 모두 같은 주소와 포트를 사용하세요.

### 평행 평판 벤치마크

Windows에서 WSL2의 Ubuntu 24.04를 열고 **OpenFOAM Foundation v14**가 설치된 셸에서 실행합니다. 설치판에서는 시작 메뉴의 **FlowForm - OpenFOAM setup**을 실행하세요. 수동 설치는 [OpenFOAM Foundation의 Ubuntu 설치 안내](https://openfoam.org/download/14-ubuntu/)를 참고하세요.

```bash
cd ~/flowform-releases
source /opt/openfoam14/etc/bashrc
python3 app.py
```

Windows 브라우저에서 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)을 엽니다. 환경 카드에서 `WM_PROJECT_VERSION`이 `14`인지와 필요한 명령의 검색 결과를 확인합니다. 포트를 바꾸려면 `python3 app.py --port 8765`로 시작하고 터미널에 표시되는 주소를 엽니다.

### CFD 단계별 화면과 격자 평가

- CFD 탭에서 형상·조건 → 격자 → 실행 → 결과 순서로 작업할 수 있습니다. 실행 기록에서 제목을 클릭하면 해당 실행을 다시 엽니다. 각 기록에 이름을 지정할 수 있고, 삭제된 기록 보기에서 복원할 수 있습니다.
- 격자 방식은 사면체 Delaunay, 사면체 HXT, 육면체 스윕, 헥스 도미넌트를 지원합니다. 두 육면체 방식은 일정한 직사각 단면의 스윕 가능한 유로에 적용합니다. 헥스 도미넌트는 모서리 열을 삼각기둥으로 분할하여 나머지 육면체 면에 정합시킵니다.
- 품질 표에는 셀별 중심선과 면 법선으로 계산한 직교성, 각 셀 면의 정규화된 각도 편차 중 최댓값인 각도 왜곡도, 구간별 셀 수가 표시됩니다. 직교성 목표는 0.9입니다. 색상 등급은 [Ansys Fluent의 품질 구간](https://ansyshelp.ansys.com/public/Views/Secured/corp/v252/en/flu_ug/tgd_user_report.html)을 참고했습니다. 수치의 정의는 FlowForm의 기하 계산을 따릅니다. OpenFOAM의 checkMesh 결과는 실행 로그에 별도로 기록됩니다.
- 비정상 해석에서는 종료 시간과 정수 스텝 수로 고정 Δt를 구합니다. 저장 간격과 유량 변경 시점은 Δt의 정수배로 지정합니다. 정상 및 비정상 해석의 실행 화면에서 p, Ux, Uy, Uz 초기 잔차를 계산 중에 갱신합니다. 비정상 해석은 현재 스텝, 지정한 전체 스텝 수, 해석 시간을 함께 표시합니다. 해석을 완료하면 결과 화면에서 최종 잔차 그래프를 다시 볼 수 있습니다.
- 실제 검증에 OpenFOAM Foundation v14를 사용했습니다. 0.3 mm U자 유로 헥스 도미넌트 격자는 육면체 588셀과 삼각기둥 168셀로 구성됐고, checkMesh를 통과했습니다. 직교성 최소 0.857493, 평균 0.963503이며 0.9 미달은 168셀이었습니다. 같은 격자로 0.0012 s까지 12스텝을 계산하고 0.0004 s에 유량을 변경했습니다. 잔차 로그에서 실제 12개 시간 단계를 확인했습니다. 같은 CAD에서 사면체 HXT 격자 3,282셀도 생성했습니다.


- 입구는 속도 또는 체적 유량과 단위를 선택합니다. 비정상 유량 변경 표에서 변경 시각(s)과 입구 체적 유량(mL/min)을 각각 입력합니다.
- 자유압력 출구는 대기 기준 totalPressure(게이지 0 Pa), 목표 정압 출구는 fixedValue를 사용합니다. 유체 온도와 기준 절대압은 실행 조건에 기록합니다. 비압축 단상 모델은 입력한 밀도와 점도를 사용합니다.
- 실행 화면의 해석 중단은 솔버 구동 중 OpenFOAM의 writeNow를 요청합니다. 격자 생성·변환·검사나 후처리 중에는 현재 단계 이후에 중단합니다.

### Windows 창에서 실행

프로젝트 Python 환경에 Windows 창 실행용 패키지를 설치합니다.

```powershell
python -m pip install -r requirements-desktop.txt
python desktop.py --port 8766 --runs-dir .\runs
```

Microsoft Edge WebView2 Runtime이 설치되어 있어야 합니다. 이 PC의 **FlowForm.lnk**는 기존 해석 기록 폴더와 설치된 Python 환경을 사용합니다. 이미 같은 포트에서 FlowForm이 실행되고 있으면 그 서비스에 연결합니다. 새로 시작한 서비스도 Windows 창을 닫은 뒤 계산을 계속할 수 있습니다.

Windows 창의 CAD 자동 저장 공간은 Chrome과 별개입니다. Chrome에서 만든 CAD는 **프로젝트 저장**으로 JSON을 내보낸 뒤 Windows 창의 **프로젝트 열기**로 가져옵니다. CFD 실행 기록은 연결한 로컬 서비스에서 공통으로 불러옵니다.



### GPU 압력 계산 (Windows + WSL)

**형상·조건 → 계산 장치**와 저장 격자의 **이 격자로 해석 실행 → 계산 장치**는 CUDA 압력 가속을 사용할 수 있으면 **GPU · 압력 계산 (CUDA)**를 기본값으로 선택합니다. GPU를 사용할 수 없으면 기본값은 CPU입니다. 계산 장치에서 CPU를 직접 선택할 수도 있습니다. GPU를 선택하면 RTX GPU의 NVIDIA cuDSS가 배정밀도로 압력 선형계의 분해와 계산을 수행합니다. 속도 방정식, 격자 생성·검사, 후처리는 기존 CPU 경로를 사용합니다. 현재 모듈은 WSL의 OpenFOAM Foundation v14 배정밀도 32비트 인덱스 빌드에서 단일 프로세스·비결합 경계를 지원합니다.

이 PC에는 모듈을 설치했습니다. 새 환경에서는 OpenFOAM v14 개발 도구와 NVIDIA GPU가 WSL에서 인식되어야 합니다. 아래 고정 버전의 휠을 받은 후 WSL에서 모듈을 빌드하고 FlowForm 서비스를 다시 시작합니다.

```powershell
python -m pip download --dest cuda-wheels --platform manylinux_2_17_x86_64 --platform manylinux_2_27_x86_64 --platform manylinux2014_x86_64 --only-binary=:all: --no-deps nvidia-cudss-cu12==0.7.1.6 nvidia-cublas-cu12==12.9.3.13 nvidia-cuda-runtime-cu12==12.9.79 nvidia-cuda-nvcc-cu12==12.9.86
wsl.exe --exec bash gpu_pressure/build-wsl.sh cuda-wheels
```

실행 로그에서 **FlowForm CUDA pressure solved on NVIDIA GeForce RTX 4060**과 **FlowFormCuDSS**를 확인할 수 있습니다. GPU 모듈이 준비되지 않았거나 해석에 실패하면 오류를 표시합니다.

같은 756셀 U자 유로에서 RTX 4060과 CPU를 비교했습니다. 정상 압력차는 GPU 18.22241306 Pa, CPU 18.22241303 Pa였습니다. 비정상 계산은 0.0012초, 12스텝에서 GPU 18.48416961 Pa, CPU 18.48432474 Pa였습니다. 전체 실행 시간은 정상 GPU 약 11.2초·CPU 약 7.9초, 비정상 GPU 약 22.8초·CPU 약 7.2초였습니다. 이 시간은 최초 CUDA 초기화와 WSL 시작·격자 변환·후처리를 포함하는 단일 실행 측정입니다. 대형 격자의 가속 여부는 별도로 측정해야 합니다.

 
#### GPU 압력 행렬 재사용

같은 OpenFOAM 솔버 프로세스에서는 압력 행렬의 연결 구조가 같으면 GPU 메모리와 행렬 분석 결과를 재사용합니다. 행렬 계수까지 같으면 수치 분해도 재사용하여 우변 벡터만 다시 전송합니다. 실행 로그의 FlowForm CUDA pressure cache 줄에서 실제 GPU 풀이, 행렬 분석, 수치 분해, 분해 재사용 횟수를 확인할 수 있습니다. 비정상 유량 변경 등으로 새 솔버 프로세스가 시작되면 캐시도 새로 시작합니다.

RTX 4060과 동일한 756셀 U자 격자에서 기존 GPU 방식과 재사용 방식으로 각각 세 번 실행했습니다. 격자 변환·검사와 후처리를 제외한 foamRun 전체 경과 시간 중앙값은 정상 3.158 → 0.468초, 비정상 12스텝 2.214 → 0.428초였습니다. 최종 입출구 압력차와 최대 속력은 수치 허용오차 1e-10 이내에서 일치했습니다. 비정상 144번의 압력 풀이 중 120번, 정상 217번의 압력 풀이 중 143번에 수치 분해를 재사용했습니다.
